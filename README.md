Steam Locomotive

What is this project?
This project is all about designing a 3D model of a classic steam locomotive using Onshape. The design includes the main boiler, smokestack, cab, wheels, cowcatcher, connecting rods, and various connection pins. My goal is to create a detailed model while improving my 3D modeling skills.

How does this project work?
This project uses Onshape(CAD software) to create a 3D model of a steam locomotive by designing its individual parts and combining them, using the assembly page, into one complete train. Each component is modeled to resemble the shape and appearance of a traditional steam engine.

Main Features:

Boiler: The main cylindrical body of the locomotive.

Smokestack: The stack on top of the boiler that allows steam to escape.

Cab: The compartment where the engineer operates the train.

Wheels: The wheels that allow the locomotive to move along the tracks.

Connecting Rods: The rods connecting the driving wheels.

Cowcatcher: The angled structure at the front of the locomotive.

Track: The thing that the locomotive runs on.

My Project Status:
I finished designing the locomotive and I'm in the process of processing the model dimensions in multiple views as if it were going through the manufacturing process.
